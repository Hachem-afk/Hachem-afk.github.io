## Project Overview

Welcome to my interactive developer portfolio! As a first-year student at Epitech specializing in innovative application development, I've created this immersive showcase of my skills and projects. The site features modern design principles, fluid animations, and interactive elements to demonstrate my technical abilities.

## Key Features

### 🌈 Immersive Visual Experience
- Interactive neural network background with dynamic connections
- Custom particle systems with physics-based interactions
- Glass morphism UI elements with smooth transitions
- Animated gradient effects throughout the interface

### 🚀 Interactive Demos
- **Real-time Raytracing**: Ocean simulation with volumetric lighting and caustics
- **3D Game Experience**: "Dimension Shift" fractal exploration using Three.js
- **Project Showcases**: Interactive modals with video demonstrations

### 🎚️ Technical Excellence
- WebGL-powered visualizations
- Custom cursor system with hover interactions
- Responsive design that adapts to all devices
- Performance monitoring and optimization
- Day/Night mode with local storage

## Installation

To run locally:

```bash
# Clone the repository
git clone https://github.com/Hachem-afk/hachem-afk.github.io.git

# Navigate to project directory
cd hachem-afk.github.io

# Install live server (if needed)
npm install -g live-server

# Start development server
live-server
```

The portfolio will be accessible at: `http://localhost:8080`

## Usage

### Navigation Guide
1. **Main Sections**:
   - Use the navigation menu to jump between About, CV, Projects, and Contact sections
   - Click the "Raytracing" link to experience the WebGL demo

2. **Interactive Elements**:
   - Hover over buttons and cards to see animations
   - Toggle day/night mode using the sun/moon icon
   - Click project cards for detailed information

3. **Raytracing Demo**:
   - Click the play button to start the ocean simulation
   - View real-time performance statistics
   - Use the back button to return to the portfolio

4. **Game Experience**:
   - Click "Discover Game" in the bottom right corner
   - Navigate through the fractal dimension
   - Find the portal to return to the portfolio

### Performance Tips
- Use Chrome or Firefox for best performance
- Enable hardware acceleration in browser settings
- Close other GPU-intensive applications
- Use a device with dedicated graphics for optimal raytracing experience

## Performance Optimization

The portfolio implements several advanced optimization techniques:

1. **Canvas Rendering**:
   - Offscreen buffers for complex scenes
   - Efficient WebGL context management
   - Texture pooling and reuse

2. **Memory Management**:
   - Object pooling for particles
   - Efficient garbage collection
   - Resource cleanup on page transitions

3. **Rendering Techniques**:
   - Level-of-detail adjustments
   - Adaptive frame rates
   - Visibility-based rendering

4. **Network Optimization**:
   - Lazy loading of assets
   - Video streaming optimization
   - Efficient resource caching
